# 📚 Lisansüstü Yönetmelik Asistanı

Lisansüstü yönetmeliği üzerine Türkçe soru-cevap yapan RAG (Retrieval-Augmented Generation) tabanlı bir yapay zeka asistanı.

## 🚀 Özellikler

- Türkçe doğal dil ile soru sorabilirsiniz
- Yanıtlar yalnızca yönetmelik belgesine dayanır
- Kaynak chunk ve benzerlik skoru gösterilir
- Top-K ayarı ile kaç kaynak kullanılacağı ayarlanabilir
- Gradio arayüzü ile kullanımı kolay

## 🛠️ Kullanılan Teknolojiler

- Python
- LangChain
- Anthropic Claude API
- Gradio
- Google Colab
- PyPDF2

## ⚙️ Kurulum

1. Google Colab'da `rag_lisansustu.ipynb` dosyasını açın
2. Anthropic API anahtarınızı girin
3. Lisansüstü yönetmelik PDF dosyasını Drive'a yükleyin
4. Tüm hücreleri sırayla çalıştırın
